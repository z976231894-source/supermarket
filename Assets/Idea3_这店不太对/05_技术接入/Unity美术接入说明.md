# 技术接入：先场景，后角色，再互动

本包是美术资产，不是Unity成品项目。未做Unity运行时验收；回读结果是Blender导出后重新导入的资产检查，不等于游戏已经可玩。

## 1. 三个关卡

`01_场景与模型/Levels/` 每关含独立 .blend / .fbx / .glb / scene-manifest.json。

- 优先导入FBX并保留原层级与名字；Unity可在模型导入器中Extract Textures、Extract Materials。默认包内贴图也可从Textures目录指定。GLB是通用备用格式，Unity项目需自行选用已有的兼容导入器，不假定Unity原生支持。
- 以米为单位，不再次整体放大100倍；先用1m标尺与2.2m牛核对尺度。Blender Z向上，Unity导出Y向上；不要导入后再给每个模型额外旋转90°。正面以实际资产验证，不以T-pose手臂方向猜测。
- `.blend` 内角色仍有骨架，默认待机放下手臂；屋顶独立集合用于总览切面。FBX/GLB有完整房顶和前墙；第一人称使用完整外壳。
- 场景FBX/GLB中的角色是 **Idle静态占位**。不能直接拿它播放动画。根据每关 `character-replacement-map.json` 的instance_id保留位置/缩放/朝向，只替换静态网格为02目录的蒙皮Prefab。
- `TRG_L*_**` 和SAFE_STAND是接入标记Empty，不是已实现的触发器。模型并未添加专用碰撞体网格；按manifest给出的建议包络建立普通Box/Capsule Collider，活动物不要直接使用高面数非凸Mesh Collider。

## 2. 骨架与动作

`02_角色与动画` 提供牛、纸箱、无臂奶盒3套真实骨架与蒙皮、14条单动作FBX及独立Blender文件。读取该目录的《角色绑定与动画接入说明.md》和动作速览。

- 使用Generic，不把非标准长颈牛/纸箱/奶盒强制套Humanoid；没有宣称通过Mixamo。
- T-pose用于绑定，Idle用于摆放。动画主要无根位移；带Root偏航的180°转身不可再叠加脚本同向旋转。
- 动作来自AI编写的参数曲线，非手工逐帧K帧。做了权重与导出回读检查；没有宣称在Unity做过IK、脚步接地或导航验收。
- 牛约2.2m、纸箱约1m、奶盒约.24m。牛尾部需要后方约.9m空间，碰撞不能用T-pose总臂展包络。

## 3. 材质和照明

- 主资产统一256px BaseColor，Point采样、sRGB、Metallic=0、Roughness约.84（Unity Smoothness约.16）。只给低像素模型贴图Point；UI用独立的UI采样设置，文字由程序渲染。
- 商品包装为新增AI图集，使用顶部12个有效格子；UV已做好，不能按每个商品重新整图平铺。原始大图和256运行图均在Textures内。
- 墙地的像素块是可导出的原生网格色块，不依赖Blender程序纹理，和用户AI模型的UV贴图分开。
- 灯管/屏幕/冷柜条有独立Emission材质；FBX材质转换可能需要在URP Lit/Unlit中重接，参数见lighting-profile.json与各关manifest。发光颜色不是实际照明：仍需烘焙静态灯或设置实时灯。
- Blender面积光、AgX调色、间接光和Bloom不可能靠FBX自动完整复现。建议静态房屋/货架烘焙，动态角色用Light Probe；各区反射探针；弱Bloom可选，不使用频闪或浓雾遮挡。
- 货架大量重复商品宜使用GPU instancing、静态合批或按货架合并静态网格；保留可选互动主物件的独立节点。预览场景为可编辑状态，没有假称已在目标设备达到帧率预算。

## 4. 自由触发，不接旧14步任务链

当前玩法核查以《飞书原案核查_2026-09-30.md》为准。每关scene-manifest包含4/5/5个可选梗，无前置顺序、无失败、无收集门槛。三关始终可从入口选择；难度是观察/转角/多物件联动的递进，不是复杂解谜。

建议实现：WASD行走、鼠标看；进入安全观察范围且视线可见时首播；E可选重播；Tab按键帮助；P可选本地拍照；Esc暂停/随时离开。玩家不被表演锁住。约20秒安静是声景节奏，不是必须等20秒才能触发。

按各关TRG编号连接03_UI中的提示文案与04_音频中的runtime/free-exploration cue映射。每次只播放一个前景梗，轻压BGM，取消或走远不丢任何“任务进度”，因为没有强制任务。

## 5. 尚需技术实测的事项

真实摄像机视线触发、场景切换/本地保存、撞墙与防落地、动态门扫掠、玩家/道具碰撞层、物件持取（如选做）、GIF以外的引擎动画表现、灯光烘焙、音频响度与空间混音、目标设备帧率、陌生玩家发现率与截图意愿。没有这些实测，不承诺最低游玩时长或“开包就是完整游戏”。
