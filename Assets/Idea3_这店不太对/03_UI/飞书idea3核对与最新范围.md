# 飞书 idea3 核对与最新范围

依据：[本次实际页面核查记录](../05_技术接入/飞书原案核查_2026-09-30.md)与[用户提供的飞书方案](https://zq6mcys13b.feishu.cn/wiki/YThTwrEyMijFwGkiipkcBuHFnqn)。主线程在登录浏览器中实际阅读了“卡3-A”和“策划案#3”；本说明引用该记录，不把本地旧稿当成原案。

原案的核心是单人 walking sim：自由走动，到观察点触发奇怪角色与物件，每场景约3–5个梗；没有任务、战斗或失败。留白和正常空间里的荒诞反差属于节奏，不是等待门槛。此前本地“14个交班事件、三箱货、完成单据”的设计偏离原案，现已退出主流程，仅作为旧稿留档，今后若复用也只能是可选彩蛋。

最新用户明确要求三个独立关卡、由简单到难，因此覆盖原MVP的单场景规模：L1便民店初访4个明显梗，L2后仓夜游5个转角观察梗，L3整店不对劲5个多物件联动梗。递增的是观察层次与联动复杂度，不增加失败惩罚、经营任务、通关锁或强制收集。任意场景都可随时进入和离开；拍照仅本地可选；20秒安静只作环境留白，绝不限制玩家推进。
