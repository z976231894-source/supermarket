# 音频来源与使用说明

本包为本项目由 AI 辅助写作、以本地确定性合成脚本实际渲染的原创编曲与程序音效，不是提示词，不是 Suno/Udio 输出，也没有借用网上歌曲、演员声音或第三方采样。

- 旋律、和声、节奏与音色参数见 Source/ui_audio_music.py。使用正弦/谐波/FM、噪声包络、循环尾音和延迟算法。牛/冰柜声音为无词合成拟声，不是真人配音。
- 生成依赖 NumPy / libsndfile (python-soundfile) 是制作工具，不将其代码或二进制随游戏打包；交付的是 WAV/OGG 成品和项目生成脚本。使用者若运行脚本，自行按依赖许可安装工具。
- 不附带第三方声音素材需要购买的许可。不主张法律意义的独占或已完成版权注册；AI辅助内容商用合规与发行平台要求由项目方最终确认。
- 3条循环与短结尾为同一主题原创变奏；不能把合成音效描述成真实录音。BGM风格为安静夜班电钢琴/塑料管乐/少量8-bit，不是恐怖氛围，也不是全程热闹喜剧。
