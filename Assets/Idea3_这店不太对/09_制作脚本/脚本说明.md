# 制作与验收源码

这些脚本是实际执行的AI辅助制作记录；场景可直接打开，不需要技术先运行脚本。

1. scene_inspect.py：读取13个ZIP，识别FBX/贴图，保留来源信息。
2. scene_prop_library.py：整理10道具的比例、UV/256贴图、活动件、FBX。
3. build_store_scene.py：结构、AI模型组装、密集陈列、AI包装UV、像素色块墙地、照明与基场景。
4. finish_store_base.py：柜台最终构图、顾客位置、补充细节、最终母场景。
5. derive_three_levels.py：从最终母场景派生三个独立可选触发关卡，导出静态占位版FBX/GLB。
6. verify_props.py / verify_three_levels.py：独立导入验收，不等于Unity运行时测试。

角色、UI、音频各目录也包含本身的制作源码。部分脚本记录了制作机绝对路径和工作目录，中间解压文件并未全部重复放入此目录；若需重跑，先调整ROOT/WORK/运行时与Blender路径。不可把该目录当未经配置的一键构建工程。

没有读取或拷贝工程.env、密钥或账户凭证。用户原始ZIP在08_原始AI输入，仅用于追溯/重新生成。
