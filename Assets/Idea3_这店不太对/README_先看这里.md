## 最容易接错的地方

1. 场景FBX/GLB里的角色是**静态Idle占位**，用于确保布局开包可见；播放动作要按character-replacement-map换成02目录的Generic蒙皮Prefab。Blender正式场景保留真实骨架。T-pose是绑定姿势，不是游戏待机。
2. 模型/贴图/发光材质可直接作为Unity资产导入；面积光、间接光、Bloom、控制器和触发逻辑不能从FBX自动带过去。详见 [Unity美术接入说明](05_技术接入/Unity美术接入说明.md)。
3. 三关4/5/5个TRG独立可选，音频按 [runtime-cue-map.json](04_音频/Data/runtime-cue-map.json) 接。玩家可随时走开或离开场景，不等20秒解锁下一步。
4. 动画为AI编写的参数曲线，未手工逐帧K；BGM为AI辅助原创程序合成，无第三方采样，**不是线上音乐模型生成**。完整制作来源在各目录说明中。
5. 导出回读和图片检查不等于Unity运行验收；尚需技术接碰撞/视线/场景切换/音频混音，再实机试玩。没有最低游玩时长或性能实测承诺。
