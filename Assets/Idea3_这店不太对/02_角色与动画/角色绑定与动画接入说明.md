# idea3《这店不太对》角色、绑定与动画

本目录是真实可导入资产，不是生成提示词。原模型来自本项目用户提供的 Tripo ZIP；没有重做角色外观，也没有操作 Mixamo。按已确认 A「低像素夜班」处理：原 UV、原配色、256 px 最近邻 BaseColor、平面法线、非金属、粗糙度 0.84。保留 ZIP 原件和各角色原始大图供回退。

## 程序拿哪些文件

| 资产 | 编辑源 | 骨骼 / 三角面 | 高度 |
|---|---|---:|---:|
| 长脖牛店员 `CHR_CLERK_COW` | `CHR_CLERK_COW/CHR_CLERK_COW_Rigged.blend` | 20 / 1500 | 2.20 m |
| 纸箱顾客 `CHR_BOX_CUSTOMER` | `CHR_BOX_CUSTOMER/CHR_BOX_CUSTOMER_Rigged.blend` | 10 / 1200 | 1.00 m |
| 无臂奶盒 `PRP_ODD_PRODUCT` | `PRP_ODD_PRODUCT/PRP_ODD_PRODUCT_Rigged.blend` | 6 / 600 | 0.24 m |

每个资产文件夹内：

- `*__Rig_TPose.fbx`：已蒙皮模型与骨架，不带动作。牛、纸箱为 T-pose 绑定姿势；奶盒没有手臂，文件名统一但实际为自然站姿，不伪造 T-pose。
- `Clips/*.fbx`：每文件只一个动作，含相同网格/骨架，便于单独导入；程序复用同一个 SkinnedMesh，不要把每个动作都实例化成新角色。
- `Textures/*_BaseColor_256.png`：正式运行纹理；`*_OriginalBaseColor.jpg` 只作源备份。FBX 内嵌正式纹理，Blend 已 packed，同时提供外置文件。
- `bone_map.json`：骨名、父级和本地米制坐标；`clip_map.json`：帧范围、时长、循环性与根运动规则；`qa.json`：本地数值检查。
- `Preview/`：T-pose、默认放下手臂、事件姿态 PNG 和短动画 GIF。GIF 为便于预览会重复播放，不代表事件动作可 Loop。

从 Blend 追加 collection 时选资产 ID 同名集合；集合中只有 `{ID}_Rig` 和 `{ID}_Mesh`。`Preview_NotForExport` 里的灯光、相机不进游戏。追加集合只保证当前 Idle 动作依赖一起导入；需要其他 Action 时，在库的 Action 分类中单独追加同资产 ID 前缀动作。

## 动作和触发建议

所有曲线由 AI 编写的参数函数自动生成并以 30 fps 烘焙，不是人工逐帧手 K；不是动作库或 Mixamo 重定向结果。非标准身形保留刻意郑重、略僵硬的喜剧节奏，不改成软萌摇摆。最新玩法以飞书原始 idea3 为准：自由走动、观察触发、无任务/战斗/失败。以下动作都是独立可选表演，不要求交班、收集或按顺序通关；旧 E01–E14 编号不再作为前置链。

| 角色 | Clip | 秒 | 循环 | 用途 |
|---|---|---:|---|---|
| 牛 | Idle | 4 | 是 | 手臂下垂、细微看头和尾部晃动 |
| 牛 | Look | 3 | 否 | 玩家靠近时视线预兆 |
| 牛 | DeepBow | 4 | 否 | 靠近柜台或注视牛时，过度郑重行礼；两段颈骨分担弯曲 |
| 牛 | Welcome | 3.6 | 否 | 延迟抬手，小幅招手 |
| 牛 | Point | 3.6 | 否 | 可选指向后仓的视觉笑点；与 Welcome 分开，指路时不挥动 |
| 牛 | SmallBow | 3 | 否 | 玩家主动道别或回头观察时的微小鞠躬，无通关门槛 |

## Unity 接入

1. 模型/动画 Rig 类型使用 **Generic**，不要自动切 Humanoid。根节点选 `{ID}_Rig` 下的 `Root`；没有 Mixamo 通用人形 Avatar。
2. Blender 单位米、Z 向上、正面 -Y；FBX 用 -Z Forward / Y Up 导出。导入后做 1 m 参照、正面 +Z 和骨架检查，不再叠加一个无条件 90°旋转。角色按高度等比，不强行拉伸至参考图 XYZ 包络。
3. 每个动画 FBX 只有一个 Take；Take 内名称可能显示 `Scene`，将 Clip 改名为文件 `__` 后缀即可。源帧表见 `clip_map.json`；Blender 重新导入的默认 +1 帧偏移不改变时长。
4. Idle / ShortStep 的 Loop Time 开启；其余关闭。Animator 常规过渡 0.12–0.2 秒，打断后过渡回 Idle，避免突然回 T-pose。
5. 所有 Clip 无根平移。ShortStep 是原地动作，沿路径移动由游戏代码驱动。ThreeStepTurn、TurnTicket、Turn180 含 **Root 骨 180°偏航**，不可同时再用脚本重复转 180°。可选方案：保留 Root 骨动画、外层物体只负责路径；或在导入中提取/烘焙旋转后改为程序转向，两者只能选一种。
6. 常规原地动作关闭 Apply Root Motion。转身结束不要直接硬切 Root 回零，否则会弹回旧朝向；应把最终偏航交给外层导航物体后归一 Root，或保留终态进入相同朝向状态。具体 Animator/导航状态需技术在项目中接入。
7. 贴图 sRGB，Filter Mode Point；主材质 URP Lit/BaseMap，Metallic=0、Smoothness=0.16。高光、写实 Normal、毛发不在本风格范围。是否 mipmap 按第一人称实际机位测闪烁，不能仅凭预览决定。
8. 面部保留原贴图的中立像素脸。本批没有伪造表情 BlendShape，也没有语音口型；需要眨眼/嘴型时再做局部脸图集映射，不用整张模型纹理替换乱闪。

## 验证与边界

已完成：3 套真实蒙皮；无未赋权顶点；每顶点最多 2 个有效权重、权重和约为 1；保留 UV；所有循环片段首尾骨矩阵一致；每片段抽样变形无非有限坐标；正面、手臂放下、鞠躬/转身姿态渲染复检。17 个 FBX（3 模型＋14 动作）全部在干净 Blender 会话重新导入，骨骼、皮肤、纹理解码、UV 和动作存在性检查通过，详见 `fbx_roundtrip_qa.json`。

为避免 Tripo 面部 UV 在焊点＋减面后被拉花，角色保留 UV 分裂顶点再自动减面，因此顶点数可能高于独立三角网格预期；三角预算已遵守。前景面部和大轮廓优先于极端压缩。自动权重已针对长颈、箱体刚性、肩部和短腿分区，不是通用人形一键蒙皮。

未完成也未宣称完成：实际 Unity 工程导入验证、游戏触发/导航、碰撞、布娃娃、IK 脚底锁定、实际镜头遮挡和首通测试。步行动作属于原地表演模板，不具备自动寻路或无滑步保证。牛鼻和尾巴是用户输入模型本身的夸张比例，原封保留；运行碰撞按躯干配置，不按整个 T-pose 包络创建超大碰撞体。
